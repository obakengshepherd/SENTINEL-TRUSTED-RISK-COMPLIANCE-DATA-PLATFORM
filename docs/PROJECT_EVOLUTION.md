## 2. Clean-start policy
Sentinel is a new engineering project. Do not import, copy, port or merge historical source code, dependencies, repository structures or Git histories.

Useful conceptual lessons may inform requirements only when independently justified and documented in the current project.

## 3. Current baseline
- Primary specialisation: Data Engineering.
- Scenario: synthetic financial risk and compliance information.
- Architecture: modular monolith.
- Database direction: SQL Server 2022.
- Scope: full phased scope delivered incrementally.
- Engineering focus: provenance, lineage, governance and auditability.
- Domain distinction: risk indicators, alerts, investigations and outcomes remain separate.

## 4. Change record
Record material changes with date, decision, reason and evidence, alternatives considered where material, impact on requirements/architecture/data integrity/security/delivery, and Product Owner approval where required.
